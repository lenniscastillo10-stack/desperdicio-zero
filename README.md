# 🌱 Desperdício Zero — Radar de Perdas

## 📌 Sobre o Projeto

O Desperdício Zero é uma aplicação web desenvolvida para auxiliar supermercados e estabelecimentos comerciais no controle de estoque, monitoramento de validade e prevenção de perdas de produtos.

O sistema busca facilitar a identificação de produtos próximos do vencimento, permitindo que os responsáveis tomem medidas preventivas e reduzam o desperdício.

Este projeto foi desenvolvido como trabalho final do curso de Desenvolvimento Web Full Stack da Toti Educação.

## 🎯 Objetivo

Desenvolver uma solução digital que contribua para uma gestão de estoque mais eficiente, econômica e sustentável.

## ❗ Problema Identificado

Supermercados podem sofrer prejuízos financeiros devido ao vencimento de produtos, à falta de acompanhamento do estoque e à identificação tardia de mercadorias em risco.

## 💡 Solução Proposta

O Desperdício Zero centraliza informações sobre produtos, categorias, lotes e ações preventivas, facilitando o acompanhamento dos itens e a tomada de decisões.

## ⚙️ Funcionalidades do Projeto

- Cadastro e consulta de produtos.
- Organização de produtos por categorias.
- Identificação visual de níveis de risco: baixo, médio e alto.
- Indicadores de produtos cadastrados e produtos em risco.
- Estrutura de backend para gerenciamento de categorias, produtos, lotes, ações preventivas e movimentações de estoque.
- Integração entre frontend e backend em desenvolvimento.

**Observação:** Algumas funcionalidades ainda estão em fase de implementação, integração ou validação.

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Node.js e npm instalados.
- Código-fonte do projeto disponível no computador.

### Executar o Backend

Abra um terminal na pasta principal do projeto:

```bash
cd backend
npm install
npm run dev
```

O servidor está configurado para funcionar localmente na porta 3000.

### Executar o Frontend

Abra outro terminal na pasta principal do projeto:

```bash
cd frontend
npm install
npm run dev
```

Acesse o endereço local informado pelo Vite, normalmente:

```text
http://localhost:5173
```

**Importante:** O funcionamento completo depende da configuração correta do ambiente e da integração entre frontend, backend e banco de dados.
